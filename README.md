# 리벤 (Liven)

마법과 오러, 그리고 재능 없는 자들의 연금술이 있는 판타지 세계 **리벤**의 설정집, 인터랙티브 지도, 세계 시뮬레이션입니다.

- 사이트: https://hoon0917.github.io/liven/
- 현재 연도: 맹약력 37년에서 시작

## 할 수 있는 것
- 지도에서 13개 나라, 섬, 화산 무주지, 마물을 눌러 정보 보기
- **다음 해 / 자동 진행**으로 세계를 흘려 보내기 (분화, 전쟁, 가문 반란, 전설급 마물, 개척, 혁명 등 30여 종의 사건)
- 조각을 조합해 매번 새로 만들어지는 사건과, 몇 해에 걸쳐 이어지는 이야기 줄기
- 연대기를 해별로 읽고, 분류별로 걸러 보기
- 인물과 나라 이름을 눌러 행적과 관계 보기
- 상태 저장·불러오기, 같은 세계를 다시 보려면 주소 끝에 `?seed=숫자`

## 폴더 구조
```
index.html        사이트 첫 화면
css/style.css     디자인
js/
  main.js         화면과 조작
  map.js          SVG 지도 그리기
  sim.js          시뮬레이션 엔진 (1턴 = 1년)
  events.js       사건 엔진
  people.js       인물 (나이, 죽음, 계승)
  monsters.js     마물 생성
  story.js        조각 사건과 이야기 줄기
  text.js         조사 처리, 문장 템플릿
data/             모든 설정과 수치 (JSON). 이 파일들만 고치면 세계가 바뀝니다.
lore/             설정 정리본 (01~09)
tools/validate-story.mjs  조각 데이터 검사 (node tools/validate-story.mjs)
BACKLOG.md        앞으로 할 작업 목록
CHANGELOG.md      변경 기록과 확인할 질문
DAILY_TASK.md     매일 자동 작업 지시문
```

## 내 컴퓨터에서 실행하기
`index.html`을 바로 열면 브라우저가 JSON 읽기를 막습니다. VS Code의 **Live Server**로 열거나, 이 폴더에서 `python -m http.server` 를 실행한 뒤 `http://localhost:8000` 에 접속하세요.

## 설정 상태
- [확정] 사용자가 확정한 설정
- [초안] 논의 중이거나 Claude가 제안한 설정
- [보류] 나중에 정할 설정

종족 세부, 국가, 가문, 사건, 시뮬레이션 수치는 현재 모두 [초안]입니다.
